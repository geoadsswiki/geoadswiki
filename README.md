# ![GeoAds](logo_geoads.svg) &nbsp; Wiki

База знаний для отдела телемаркетинга. Содержит скрипты разговоров, ответы на возражения, регламент работы и примеры звонков.

---

## Для чего

Помогает телемаркетологам быстро находить нужные скрипты, правильно отрабатывать возражения и соблюдать регламент при передаче сделок.

---

## Состав

- Скрипты для автосервиса и стоматологии (платный / не платный)
- Ответы на частые возражения
- Чек-лист подтверждения встречи
- Примеры звонков (аудио)
- Видео-обзор работы
